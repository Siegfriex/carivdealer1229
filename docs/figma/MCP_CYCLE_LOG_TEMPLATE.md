# MCP 사이클 로그 템플릿

사이클마다 아래 **체크리스트 블록**을 복사해 채운 뒤 [MCP_CYCLE_LOG.md](MCP_CYCLE_LOG.md)에 해당 사이클 행을 추가한다.  
**요약 표**는 사이클이 쌓일 때마다 업데이트한다.

---

## 체크리스트 블록 (사이클마다 복사·채우기)

```markdown
## 사이클 [N] — §[X].[Y] [섹션 이름]

| 항목 | 내용 |
|------|------|
| **섹션 번호·이름** | §3.X [이름] |
| **이번 사이클 nodeId (최대 3개)** | nodeId1, nodeId2, nodeId3 (또는 1~2개) |
| **동일 라우트 여부** | 동일 route 1페이지 / 서로 다른 route (IA 확인) |
| **대응 라우트** | `/path`, `/path/:id` 등 |
| **대응 페이지 파일** | pages/.../PageName.tsx, widgets/... |
| **MCP 호출** | get_design_context: N회, get_metadata: N회, get_screenshot: N회 |
| **API/ERD** | 사용 엔드포인트: GET/POST ...; 엔티티: xxx (api_v1·ERD Mapping 반영 여부) |
| **스크린샷 검증** | nodeId ↔ 구현물: OK / 수정 필요 (내용 간단 기재) |
| **비고** | 동일 페이지 상태 변형인 경우 IA §3.X 참고·맥락 기재 |
```

---

## 요약 표 (사이클 인덱스–섹션–nodeId–라우트)

MCP_CYCLE_LOG.md 상단 또는 별도 섹션에 아래 표를 두고, 사이클 완료 시마다 한 행씩 추가한다.

| 사이클 | 섹션 | nodeId (최대 3개) | 대표 라우트 | 상태 |
|--------|------|-------------------|-------------|------|
| 1 | §3.1 랜딩 | 1368:37201, 37364, 43715 | `/` | 미실행 |
| 2 | §3.2 로그인·회원가입 | 1425:7280, 7613, 1513:12032 | `/login`, `/signup` 등 | 미실행 |
| … | … | … | … | … |

**상태**: 미실행 / 진행 중 / 완료
