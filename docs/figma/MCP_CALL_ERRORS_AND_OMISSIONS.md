| 경매 전 단계(SCR-0400, 0401-A~0403-A) | 동일 |
| 탁송 예약/내역(SCR-0600, 0601) | 동일 (탁송은 2026-02-08 11프레임 design_context 완료로 §3.10에서 보완됨) |

- 위 항목은 "페이지 프레임 목록에 nodeId가 (확보 필요)로 되어 있거나, SCR에만 있고 Figma 자식 트리 미확인"인 경우. 탁송·정산은 이후 정합성 작업에서 자식 nodeId 확보 후 design_context·get_screenshot 호출 완료.
- **한계·리스크**: 위 페이지(정산·탁송 제외)는 nodeId 미확보 또는 design_context 미호출로 SS-only/문서 추정에 의존하며, 디자인-코드 정합성 검증 제한·누락 UI 가능성이 있음. 정산(§3.11)·탁송(§3.10)은 보완 완료.
