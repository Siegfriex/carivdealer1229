## 6. 위험/주의사항

- **컨테이너 클릭 시 아래로 스크롤**: 상단 컨테이너(차량정보·전체 피드백·검차자 카드)를 클릭하면 detailSectionRef(세부 검차내역 섹션)로 smooth 스크롤. 키보드 포커스 시 Enter/스페이스로 동일 동작. aria-label="아래 세부 검차내역으로 이동" 필수.
- 검차내역 페이지는 "아래로 내릴 경우" 별도 뷰(1193-9217)가 있으므로, 스크롤 목적지를 세부 검차내역 블록으로 정확히 지정.
