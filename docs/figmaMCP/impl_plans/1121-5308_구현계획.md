## 6. 위험/주의사항

- 매칭중·이동중 단계에 **임시저장** 버튼 필수. 클릭 시 /inspections(목록)으로 이동.
- 개발 모드(npm run dev 또는 VITE_RUN_DEV=true)에서만 **다음단계** 버튼 노출. 필수 입력 없이 매칭중 → 이동중 → 검차완료 순서로 진행 가능.
