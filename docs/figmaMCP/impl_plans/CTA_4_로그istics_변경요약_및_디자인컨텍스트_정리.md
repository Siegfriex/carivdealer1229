## 4. 권장 수정 (design_context 반영)

1. **탁송 장소**: 섹션 제목을 **"탁송 장소"**로 변경.
2. **탁송 일정**:

   - 안에 **날짜 선택** * (선택 값은 가능하면 "2026년 1월 25일 일요일" 형식), **시간 선택** * (오전/오후 표기 유지).
