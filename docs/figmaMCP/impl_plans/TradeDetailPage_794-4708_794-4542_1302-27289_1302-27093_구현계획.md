# 구현 계획: TradeDetailPage (거래상세 변형·펼침·모달·판매방식 변경 컨테이너)

**페이지 컴포넌트**: TradeDetailPage

## 1. 목표

- **794-4708 / 1123-14112**: 거래상세 리스팅 컨테이너. **클릭 시 아래로 펼쳐지는 뷰**(794-4542 / 1123-13946) 토글.
- **1302-27289**: 컨테이너 내 "검차 상세내역" 버튼 클릭 시 **모달**로 세부 검차내역(사진항목·영상항목, 아코디언) 표시.
- **1302-27093**: 경매 플로우 시 "판매방식 변경 및 판매가 수정" 컨테이너. "검차 상세내용 확인" 버튼, "총 111개의 항목이 검사되었습니다." 문구.
