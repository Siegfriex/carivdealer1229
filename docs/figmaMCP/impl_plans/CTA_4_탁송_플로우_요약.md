# CTA_4 탁송 플로우 구현 요약 (§3.5, §3.10)

**플로우 요약**: 판매/거래목록 → 탁송 해당 페이지 → 새 탁송예약(우편·주소 모달·연도/월/일·시간) → 기사배정 진행중 → 탁송완료. 탁송완료 시 **탁송목록으로 돌아가기** 또는 **정산단계 진행**(정산은 인계확정 시만 가능).

**전제**: GNB 탁송 탭과 차량목록 탭의 "탁송단계 필터"는 **서로 다른 페이지**이다. 별도 라우트·화면으로 유지한다.

**거래(CTA_3)에서 목록 돌아가기**: 매물등록 CTA_3 거래 단계에서 목록 돌아가기는 **GNB 탁송 탭** (`/logistics/schedule`)으로 이동함을 명확히 한다.

## 3. 플로우

- §3.5_1418-22630_판매_거래목록_목록뷰-1 2 → 탁송 해당 페이지로 자연스럽게 이동 후 **본격 탁송** (1272-12926).
- **새 탁송예약** 버튼 → 1272-13294 (폼).
  - 우편번호 버튼 → 1272-14540 (주소검색 모달, 텍스트 입력 시 주소결과). X 버튼으로 모달 닫으면 폼으로 복귀.
  - 날짜 클릭 → 1272-13503 (연도 캘린더) → 1272-13819 (월 3*4) → 1272-14309 (일·시간).
- 폼 작성 후 **완료** 버튼 → 1272-15049 (기사배정 진행중).
- 진행중 → 완료 상태 저장 시 → **1272-13099 (탁송완료)**.
  - **탁송목록으로 돌아가기** 또는 **정산단계 진행** 분기.
  - **정산단계 진행**은 반드시 **탁송 인계 확정** 상태일 때만 가능.
