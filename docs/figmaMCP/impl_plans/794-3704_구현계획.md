## 6. 위험/주의사항

- InspectionCompletePage에서 "경매로 판매하기" 클릭 시 현재는 /auction/start-price로 직행. Figma 플로우는 "판매방식선택 → 경매 선택 → 시세분석중 → start-price". 진입을 /sale/analyzing으로 통일하고, 쿼리 type=auction이면 794-3704 생략 후 시세분석중만 짧게 보여주고 start-price로 보내는 선택 구현 가능.
- 카드 클릭 시 로딩(시세분석중) 1~2초 후 이동 처리.
