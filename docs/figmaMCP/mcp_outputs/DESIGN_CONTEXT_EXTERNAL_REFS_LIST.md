# MCP Output 내 디자인 컨텍스트 외부 참조 목록

**목적**: `mcp_outputs` 내 `design_context_raw.txt` 중 (1) **외부 파일 경로로만 연결된 항목**과 (2) **Figma MCP asset URL이 포함된(풀 디자인 컨텍스트) 항목**을 식별·리스트업.

**검증 방법**: `grep`으로 `https://` 및 `agent-tools` 패턴 검색, 파일 내용 샘플 확인.  
**검증 시점**: 2025-02-10.

**2025-02-10 인라인 처리**: 아래 §1에 있던 14개 노드의 `design_context_raw.txt`는 agent-tools 원본 파일 내용을 **복사해 덮어쓰기**하여, 한 줄 경로 참조가 아닌 **풀 디자인 컨텍스트 텍스트**로 통일됨. 현재는 외부 경로 참조 없이 모두 로컬 풀 텍스트 보유.
