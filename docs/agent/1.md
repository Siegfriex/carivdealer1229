이 디자인은 프로젝트의 Figma SSOT 워크플로에 따라 구현한다. 너는 **1번 에이전트**다.

[역할] MCP 호출 + mcp_outputs 폴더·파일 생성 + 사용자 붙여넣기 안내
- MCP(get_metadata, get_design_context)를 호출한다.
- mcp_outputs 파일만 읽고 Phase 4~7을 수행하지 않는다. 그건 2번 에이전트가 한다.

1) URL에서 식별자 추출
- Figma URL에서 fileKey와 nodeId를 추출한다. node-id=1444-7928 형식이면 nodeId 하이픈은 1444-7928이다.
- fileKey: URL 경로 design/ 다음 값(예: 4w3ft8RpGwoho5EtvNO9hQ).

2) Phase 1·2 수행
- get_metadata(fileKey, nodeId 콜론 형식 예: 1418:24679) 호출.
- get_design_context(fileKey, nodeId) 호출.
- 필요 시 get_screenshot 호출.

3) 폴더·파일 생성
- docs/figmaMCP/mcp_outputs/{nodeId하이픈}/ 폴더 생성.
- metadata_raw.txt, design_context_raw.txt 생성(빈 파일 또는 placeholder).

4) 사용자 안내 (MCP 반환값이 잘린 경우)
- "UI에 표시된 get_metadata·get_design_context 반환 **전체**를 복사하여, 각각 mcp_outputs/{nodeId}/metadata_raw.txt, design_context_raw.txt에 붙여넣어 주세요. 붙여넣기 완료 후 같은 Figma URL에 2번 에이전트 프롬프트(AGENT_PROMPT_TEMPLATE.md)를 붙여 구현을 요청하세요."

5) MCP 반환값이 온전한 경우
- 응답 내용을 metadata_raw.txt, design_context_raw.txt에 바로 저장(또는 사용자에게 저장 경로·내용 안내).

6) 문서 참조
- docs/figmaMCP/WORKFLOW.md Phase 1·2
