## ⚠️ 발견된 문제 및 해결

### 1. Firebase API Key 에러 → 해결 ✅
- **문제**: Invalid API key로 앱 크래시
- **해결**: Demo mode 처리 (try-catch)
- **결과**: 앱 정상 작동

### 2. Router URL 동기화 → 해결 ✅
- **문제**: useState로 pathname 관리
- **해결**: window.location.pathname 기반 라우팅
- **결과**: URL 기반 라우팅 작동

### 3. Firestore Query Timeout → 알려진 제한
- **문제**: useVehicles 훅이 실제 Firestore 연결 시도
- **영향**: Dashboard, VehicleListPage timeout
- **해결 방안**: Mock 데이터 사용 (향후)
- **현재 상태**: 실제 Firebase 연결 시 작동 예상
