## 6. API-only / DB-only / 계산값 점검

- **API-only (저장 필드 없음)**: isNew(계산값), tokens.accessToken(Redis), pledge.agreed(ERD 없음) — DBML·매핑 문서와 일치.  
- **DB-only (API 미노출)**: last_login_at, approval_status, reject_reason, expires_at, address_type, post_code, full_address 등 — DBML에 컬럼 존재하고 note에 "DB-only" 표기됨. ✅  
- **계산값**: nextStep, displayStatus, primaryCta, canEdit, latestInspectionStatus, isNew — DBML 해당 컬럼에 note로 "계산값" 명시됨. ✅  

---

## 7. DBML 전용 검증 (ERD 이미지 대비)

- DBML에만 있는 확장 제안 테이블(auction, auction_bid, logistics_schedule, settlement, sales_history, offer)은 매핑 문서 §경매·탁송·정산·오퍼 제안과 일치.  
- ERD 테이블·컬럼 목록(매핑 문서 §ERD 테이블·컬럼 목록)의 모든 테이블·주요 컬럼이 DBML에 포함됨.  
- PK/FK/Ref: DBML의 ref: > 관계가 매핑 문서의 FK 설명과 일치.
