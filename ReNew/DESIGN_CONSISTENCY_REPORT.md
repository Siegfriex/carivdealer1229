## 3. Figma vs 구현 대조 (요약)

Figma 스크린샷 설명과 현재 구현을 기준으로 한 대조입니다.

### 3.1 차량등록 완료 (915:998)

- **Figma**: 성공 아이콘, "차량 등록이 완료되었습니다.", "홈으로 돌아가기" 버튼.
- **구현**: `VehicleRegistrationCompletePage` — "홈으로 돌아가기", "검차 진행하기" 버튼, 1440px 컨테이너.
- **정합성**: ✅ 제목·버튼 구성 일치. (Figma에 "검차 진행하기"가 없을 수 있음 — 플로우 추가 버튼으로 구현 유지 권장.)

### 3.2 검차신청 랜딩 (1202:6390)

- **Figma**: 사이드바(검색, 단계), "검차 신청" 제목, "검차 신청하기", "임시저장" 버튼.
- **구현**: `InspectionRequestLandingPage` — 사이드바(검색, 단계 1·2·3), H1 "검차 신청", 동일 버튼.
- **정합성**: ✅ 구조·라벨 일치.

### 3.3 검차 신청 목록 (1202:6685, 1202:7020, 1202:7204)

- **Figma**: SegmentedControl(전체 N, 검차자 매칭중, 검차자 매칭완료, 검차중, 검차완료), 테이블/카드, 확장 시 상세(희망일시, 평가사, 상태).
- **구현**: `InspectionListPage` — SegmentedControl(전체, 검차자 매칭중, 검차자 이동중, 검차 진행중, 검차 완료), 리스트 행 클릭 확장, 희망일시·평가사·상태 라벨.
- **정합성**: ✅ 라벨 "검차자 이동중"(구현) vs "검차자 매칭완료"(Figma) — 용어 차이만 있음. 기능·구조 일치.

### 3.4 검차 진행 (1202:7440, 1202:7752, 1202:7902)

- **Figma**: "검차 진행상황", 단계 스텝퍼(검차신청→검차자 매칭→검차중→검차완료), 매칭중/이동중/완료 섹션.
- **구현**: `InspectionProgressPage` — "검차 진행내역", ProgressSidebar, 1/3·2/3·3/3, DEV:SKIP·스킵·검차내역 보기.
- **정합성**: ✅ 단계 흐름 일치. "검차 진행상황"(Figma) vs "검차 진행내역"(구현) — 문구만 상이, 수용 가능.

### 3.5 검차내역 (1202:7588)

- **Figma**: "검차내역" 제목, 차량정보·전체 피드백·검차자·세부 검차내역 카드.
- **구현**: `InspectionHistoryPage` — "검차내역" 제목, 완료 목록(검색, 행 클릭 → 상세).
- **정합성**: ⚠️ Figma는 상세 뷰(차량정보·피드백·검차자·세부내역); 구현은 목록 뷰. 목록 → 상세(`/inspections/:id/complete`)는 구현됨. 상세 페이지(InspectionCompletePage)와 Figma 상세 뷰 비교는 별도 검토 권장.
